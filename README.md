# BOSS skill

One skill family for four jobs: **WEB** (websites), **APP** (mobile apps), **PROMPT** (prompts and agent work orders),
**AUDIT** (audits of sites, apps, repos and specs). Three editions from one source: Claude Code (E1, with scripts),
Claude.ai (E2, no scripts), Gemini (E3, no scripts).

What it makes the model do, in order: route the task by mode and size; for UI work write the acceptance list, study the
domain, write a short design brief, roll a divergence seed and compare three genuinely different directions, plan every
element's position in text before styling, derive tokens with computed contrast, critique the first screen from
screenshots, then build the rest with real content and every state; verify with scripts (or manual checklists); and
report with evidence labels. It ships no palettes, fonts or layout templates: every project gets its own design.

**Verdict: NOT-MEASURED indicative, n=0.** The benchmark against the three source skills was not run (deferred by the
operator to save tokens; see Limitations). Nothing here claims BOSS produces better output than the sources; that is
an open hypothesis for the next session.

## Download `boss.skill` (one tap)

**https://github.com/starmovie12/Boss-skill-/raw/main/boss.skill**

Open that link on your phone: the file `boss.skill` downloads directly (do not use GitHub's green "Code > Download ZIP"
button, which downloads the whole repository). Then on claude.ai: Settings, Capabilities, Skills, upload `boss.skill`
(menu names may differ by plan and app version: UNVERIFIED). Inside, it is the standard skill archive: a `boss/` folder
with `SKILL.md`, `modes/`, `references/` and `scripts/`.

## Install (phone-first)

### E1: Claude Code on the web (your project repo)
1. Open your project in Claude Code on the web (claude.ai/code) on your phone.
2. Paste: `Copy the folder editions/e1-plugin/skills/boss from https://github.com/starmovie12/Boss-skill- (branch main once the PR is merged) into .claude/skills/boss in this repo, commit and push.`
3. Start a new session on that repo; ask for a website, app, prompt or audit. Cloud sessions load skills committed under `.claude/skills/` (docs, verified 2026-11-12).

E1 on claude.ai: use the `boss.skill` download above (the same archive also exists as `editions/e1-plugin/boss-skill.zip`).

### E2: Claude.ai Project (free or paid; no scripts)
1. claude.ai, Projects, New project, name it BOSS.
2. Open `editions/e2-claude-free/project-instructions.md` on GitHub, copy all, paste into the project instructions.
3. Add every file in `editions/e2-claude-free/knowledge/` to the project knowledge.
4. Chat in the project; start with "Boss: WEB" (or APP, PROMPT, AUDIT) to force a mode.
No Projects? Paste `editions/e2-claude-free/paste/boss-web.md` (or app, prompt, audit) as your first message.

### E3: Gemini Gem (no scripts; untested here)
1. Gemini app, Gems, New Gem (if your account shows skills instead of Gems, use the same text there).
2. Paste all of `editions/e3-gemini-free/gem-instructions.txt` (3,560 characters) into the instructions.
3. Upload the 10 files in `editions/e3-gemini-free/gem-knowledge/` as knowledge. Save.
4. Run the three test prompts in `docs/PHONE-TEST.md`. Limits are UNVERIFIED.

## Layout
- `src/boss-skill/` the skill: `SKILL.md` (kernel), `modes/` (web, app, prompt, audit), `references/` (placement, design-system, quality-gates, stacks, audit-checklists, india, domains/fintech-trading), `scripts/` (9 standard-library scripts).
- `editions/` ready-to-install copies, generated by `python3 tools/build_editions.py` (`--check` proves a byte-identical rebuild).
- `examples/synthetic-case-study/` a fictional broker worked through all four modes, with real script output.
- `tests/` unit tests for every script (`python3 -m unittest discover -s tests`).
- `docs/` phone test, build notes, and the next-session plan. Full build records (source ledger, field study, rule audit) are in git history.

## Evidence that exists
- Size: about 21,700 estimated tokens of prose (budget 30,000; every file within 10 percent headroom) - `python3 src/boss-skill/scripts/token_budget.py`.
- Health: `python3 src/boss-skill/scripts/boss_doctor.py` PASS (paths, output contracts, no color literals, fonts only in the habits list).
- Placement checker: flags a planted overlap, off-screen element, tiny target, covered primary action and horizontal scroll, and passes a clean page (tests).
- Worked WEB example: `boss_verify.py` exit 0 with axe 0 serious or critical and no placement hits at 360 and 1280 px; the checks forced five fixes recorded in its craft log, including two defects in the scripts themselves.
