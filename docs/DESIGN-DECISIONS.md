# Design decisions (decision | reason | rejected alternative)

1. Work on the harness branch `claude/hopeful-fermat-35aqea`, mirror to `boss-skill-forge` at phase ends | the harness and the one-tap PR flow are tied to the session branch; a stale FORGE_STATE.md on the probe branch would mislead a resume | deleting the probe branch (no deletions) or working on it (PR flow unknown).
2. Forge-level tools live in `tools/` (ledger_check, isolation_check, build_editions, boss_doctor); skill-runtime scripts live in `src/boss-skill/scripts/` | AC-10 needs ledger tooling committed before any `src/boss-skill` content | putting every script under `src/boss-skill/scripts/`.
3. Sources are named S1, S2, S3 everywhere; unit titles and file names of the sources are not committed | the repo is public | committing titles for readability.
4. Unit ids are line-anchored (`S1-0480`) and regenerated by regex | deterministic diff of ledger against raw sources | hand-numbered units.
5. Extraction shards write neutral summaries plus up to three mechanism notes per unit; long digests stay in /tmp | ledger must not carry source text; the skill author still needs the mechanisms | committing digests.
6. The work order attached is v2.9 while the chat message names v2_7 | the attached file is the only work order present | stopping to ask.
