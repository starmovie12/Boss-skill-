# Design brief: Tarang demo desk (fictional broker, demo data)

Audience: retail traders in India who check positions several times a day, often in the evening, on a phone first and a laptop at the desk. Key task: see what moved, decide, place a correct order without mistakes. Surface modes: Operate (ticket, watchlist), Read (portfolio, chart).
Adjectives: calm, exact, trustworthy. Anti-adjective: casino.

Domain study (from knowledge, no web access used): keep: dense watchlist rows, tabular numerals, buy and sell as distinct colored actions, margin shown before confirming, previous-close reference on the chart. Avoid: confetti or celebration on fills, red/green as the only signal, flashing tickers that pull attention, promotional banners inside the trading surface. Depart: the portfolio value is the one hero number (most dashboards give equal tiles), and the stale-feed state is spoken plainly in the status line instead of a tiny icon.

Seed roll 2611 and overrides: density dense data, table-first (kept); shape fully round (kept for pills and actions; tables stay square for density); type voice humanist warmth (kept as a humanist system sans; handwriting rejected for trust); color dark base with luminous accents (kept: evening use; amber reserved for focus and the primary action, mint and coral only for gain and loss); imagery texture from the domain (a faint price-grid ruling in the background); layout single column editorial (kept at 360 px; at 900 px and up overridden to watchlist left, workspace center, ticket right, the domain convention); motion scroll-linked reveals (overridden: none; only a 220 ms row tint on price change, off under reduced motion).

Directions considered: 1 "Night desk" dark base, luminous signals, pill controls, one hero number (chosen: fits evening use and calm-exact). 2 "Ledger paper" warm light paper, serif headings, ruled tables (rejected: weaker at night, serif numerals hurt scanning). 3 "Signal strip" mid-gray with a single neon band showing market state (rejected: the band competes with gain and loss signals).
Category test: brokers default to blue and white or black with saturated green and red; this uses amber as brand and pairs every color signal with arrows and signs. Specificity: the price-grid ruling and the plain-language stale line exist only because this is a live-price product.
Memorable thing: "Exact numbers, calm surface: you always know if a price is live."
Light or dark: dark, from the evening use scene; no light theme in this example (one line: scope of a worked example).
